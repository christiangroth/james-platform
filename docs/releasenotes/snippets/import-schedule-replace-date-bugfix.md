* Beim Import landen Datumswerte mit Zeitzone (z. B. Mitternacht deutscher Zeit in UTC) nicht mehr auf dem Vortag.
* Import-Definitionen können bei jedem automatischen Lauf die vorhandenen Daten ersetzen statt sie zu ergänzen.
* Slack-Benachrichtigungen zu automatischen Importen kommen nur noch, wenn sich Daten geändert haben oder der Lauf fehlschlägt.
* Zeitpläne von Import-Definitionen lassen sich über die API setzen.
