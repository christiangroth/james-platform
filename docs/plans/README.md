# Concepts & Plans

This folder collects proposals, concepts, and implementation plans for work that has **not been built yet**.

- Once a plan here has been implemented, delete it — don't leave it as stale documentation. If any of its content should live on as reference architecture, fold that into [docs/arc42/arc42.md](../arc42/arc42.md) or an ADR in [docs/adr](../adr) as part of the same PR.
- This folder is for concepts and plans only. Role guidelines live in [docs/coding-guidelines](../coding-guidelines); implemented architecture lives in [docs/arc42/arc42.md](../arc42/arc42.md).

See the "Keeping Documentation Current" and "Concepts & Plans" sections in [CLAUDE.md](../../CLAUDE.md) for the rules around this folder.
